## 搜索边界

- 本地内存索引仅来自显式允许的公开静态字段：八页面及功能入口、课程大纲、公开论文、师资、菜单、社团、学位与专业选项、公开校长与公告、隐私及条款入口。
- 在用户数据渲染前复制静态索引；公告更新只读取既有公开 JSON。搜索不遍历页面 DOM，不读取 Firebase 身份、云端档案、localStorage 或用户生成论文，不索引测验题目及答案。
- 查询支持中英文互搜、大小写与全角/空白规范化、多关键词匹配及相关度排序。界面最多输入 120 字符、展示 24 条结果；无结果可清空重试。
- 查询只保留在当前页面内存，不发送到服务端、不写入 URL 或持久存储。结果使用文本节点，查询不会成为 HTML 或正则表达式。
- 搜索支持菜单及手机顶栏入口、Ctrl/Cmd+K、上下键、Enter 和 Esc。原生 dialog 管理模态焦点，关闭后恢复入口；手机侧栏关闭时不可聚焦，打开后锁定背景并支持键盘关闭。
- 课程、论文、公告、菜品、师资和社团结果定位对应内容；需要时清除阻挡目标的课程、公告或食堂分类筛选。
